# Polish releases

Installers and update feeds for [Polish](https://polish.matricetechnologies.com),
the desktop app that rewrites selected text in any app with a keyboard shortcut.

**Download the latest version from https://polish.matricetechnologies.com/download**
or from the [latest release](https://github.com/matrice-technologies/polish-releases/releases/latest).

| | |
| --- | --- |
| Windows 10 and 11 (x64, Arm64) | `Polish-Setup-<version>.exe` |
| macOS, Apple Silicon | `Polish-<version>-arm64.dmg` |
| macOS, Intel | `Polish-<version>-x64.dmg` |

Installed copies update themselves from this repository. It holds release
artifacts only; there is no source code here.
